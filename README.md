# Fu-Yu Chen — Personal Portfolio

A responsive, bilingual (Traditional Chinese / English) personal portfolio website built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — responsive visual design
- `script.js` — language toggle and dynamic year

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `fu-yu-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, your site will be available at `https://YOUR-USERNAME.github.io/fu-yu-portfolio/`.

## Before publishing

1. The contact email is set to `a3508178@gmail.com`. Update it in `index.html` if it changes.
2. Review project descriptions and add real screenshots, GitHub repository links, demo links, datasets, and measured results where available. Three project report links currently open the supplied Google Drive files.
3. Add your own portrait if you want one. The current hero uses a typographic monogram placeholder.
4. Check that you are comfortable making all published information and images public.

## Customize

- Update the content in `index.html`.
- Update Chinese and English translations in `script.js`.
- Adjust colors, spacing, and typography in `style.css`.
